How to use this page

Look up verses by reference

Type a reference; verses appear as you type. Separate several references with ;

  • Gen. 1:1   Eph. 4:4-6   Rev. 21:2, 9-10   Rom. 6:3-5; 8:4
  • John 1 whole chapter   Gen. 1-2 whole chapters   Jude 9 single-chapter book
  • Gen. 1:4-2:3 across chapters   Gen. 1-2:3 chapter 1 start through 2:3
  • Gen. 1:5-2 (second number smaller) means 1:5 to the end of chapter 2
  • Gen. 1:5-7 with a normal hyphen means verses 5 to 7; with an em dash (—) it means 1:5 through the end of chapter 7

Full names, abbreviations and short forms all work (Romans, Rom., rom). Also: jdg Judges, jud Jude, phm / philm Philemon.

Search by words

  • light finds every verse containing it; god created needs both words
  • "in the beginning" (quotes) finds the exact phrase
  • Start with ? to force a word search, e.g. ?mark or ?job, since those are also book names

Keyboard shortcuts

/Jump to the text box from anywhere
?Open this help (when not typing in the box)
Tab ↓From the text box, move into the verses

In the verse list

↓ TabNext verse
↑ Shift+TabPrevious verse (on the first verse, either one returns to the text box)
← / →First / last verse listed (Home / End also work)
Shift+↑↓←→Select several verses
H J K LSame as ← ↓ ↑ → (hold Shift to select); these also work in presentation mode
Ctrl/Cmd+ASelect all listed verses

EnterPresent the current verse, maximized in the window (Shift+F for true full screen)
EscClear the selection; press again to return to the box

Presentation mode

→ ↓ Space Page DownNext verse

FFill the presentation area with the verse (largest size that fits)
Shift+FToggle true full screen (the browser’s Esc leaves it but stays in presentation mode)
Enter EscExit, returning to the verse you were on

Touch screens

Tap verses to select or deselect them. A bar at the bottom lets you Copy (the selected verses, or all listed if none are selected), Present, and Select all / Clear. In presentation mode, swipe left or right (or use the buttons) to change verse, A− / A+ to resize, Fill to fill the screen, and × to exit.

Mouse

Click a verse to select it, Shift+click to select a range, Ctrl/Cmd+click to add or remove one, double-click to present.
